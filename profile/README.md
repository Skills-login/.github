## Chúng tôi làm gì / What we do

Velclaw là một không gian làm việc phần mềm hợp nhất: agent, code, project,
build, runtime, storage, review, và deploy — tất cả trong một workspace,
thay vì rải rác qua nhiều công cụ rời rạc.

Velclaw is a unified software workspace covering the full lifecycle:
agents, code, projects, builds, runtime, storage, review, and deployment —
one coherent environment instead of disconnected tools.

> Build software. Give agents context. Keep the workflow together.

## Năng lực chính / Core capabilities

- **AI Agents** — quy trình phát triển và thực thi công cụ do agent điều khiển
- **Workspace** — project, file, code, context và state bền vững
- **Build & Runtime** — build, kiểm tra, đóng gói và thực thi phần mềm
- **GitHub** — tích hợp repo, review code, quy trình bàn giao
- **Deployment** — đưa phần mềm đã kiểm định vào production
